# A股打新工作台

A 股（沪市主板 / 深市主板 / 科创板 / 创业板）与北交所新股申购、可转债打新的一体化研究工作台，单页静态应用。

- 主页：`index.html`（A股打新工作台）
- 旧版：`beijiaosuo.html`（原「北交所打新工作台」，保留备份）

## 栏目结构

| 分组 | 栏目 | 内容 |
|---|---|---|
| 主板打新 | 打新总览 | KPI 看板、待发新股日历、近 6 个月各板块发行量、近 20 只新股首日涨幅、14 天打新日历 |
| | 沪市主板 / 深市主板 / 科创板 / 创业板 | 各板块申购规则 + KPI + 新股列表 + 打新日历 |
| 可转债 | 可转债打新 | 待发/待上市转债、全量列表、首日涨幅分布、单签收益 TOP15 |
| 北交所 | 北交所打新 | 审核流程看板、阶段公司列表、发行排期、权限自查、单只资金测算、收益率回测、三情景测算、历年收益率明细 |
| 研究 | 市场趋势 | 全板块对比 6 图（月度发行量 / 月度冻资 / 首日涨幅中位 / 中签率中位 / 市盈率散点 / 涨幅分布）+ 北交所长周期 65 个月发行量 |

| 中心 | 提醒中心 | 本周申购预告、提醒列表 |

## 数据口径

- 沪深 / 科创板 / 创业板 / 北交所新股与可转债台账、北交所审核数据：近 13 个月（2025-07 ~ 2026-09），来源东方财富数据中心、北交所官网审核披露
